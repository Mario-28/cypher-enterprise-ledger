# Cypher Enterprise Ledger v1.2.0
Foundry VTT v14+. Magitech steampunk visual redesign.

## UI redesign
- Engraved brass tab plates with SVG icons, a crystal-lit title plate and round instrument-gauge badges.
- Counting House uses four animated dial gauges (income, costs, profit, morale), a parchment graph, and a prominent copper month-close control.
- Procedural tileable walnut, brass, and parchment textures are bundled locally; no external image dependency.
- Optional wide banner image setting lets a GM add a setting-specific header. Leave blank for the built-in textures.
- Existing GM/player permissions, actions, drag/drop, and data model are retained.
- Reduced-motion preference disables the animations.

Install: replace the existing module folder with the folder in the zip, then reload Foundry. Your saved ledger data is preserved.
