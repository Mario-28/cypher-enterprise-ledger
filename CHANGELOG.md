# Changelog

## 2.2.0 — Theme Artwork
- AI-generated artwork for each of the five themes: a wide header/workspace backdrop and a square emblem.
- Header artwork sits on the right, darkened so the company name stays readable.
- Workspace uses the same artwork as a fixed, dimmed background.
- Emblem image appears in the header next to the company name.
- Fonts, fonts and backgrounds all bundled — no network access needed.

## 2.1.0 — Theme Pack
- Five new visual themes: Magitech, Steampunk, Fantasy, Cyberpunk, Sci-Fi.
- Each theme swaps fonts, colours, backgrounds, borders and card styling.
- Bundled Google Fonts (OFL) and generated SVG backdrops — no network needed.
- Reduced-motion users get static backdrops automatically.

## 2.3.0 — Visual Polish
- Upgraded buttons: gradient fills, shine sweep on hover, spring-lift, and press-down effect.
- Primary action buttons: 3D "chunky" style with a raised bottom edge and drop shadow.
- Card entrance animations with staggered delays when multiple cards render in a grid.
- Cards lift on hover with a soft accent glow.
- Danger cards and blocked routes pulse continuously.
- Metric values count up; badges pop in; progress bars animate their fill.
- Per-theme flourishes: magitech arcane pulse, steampunk gear spin, fantasy candle flicker, cyberpunk glitch, sci-fi holographic shimmer.
- All animations respect `prefers-reduced-motion`.

## 2.3.1 — Legibility Fix
- Body text now uses Rajdhani (clean sans-serif) in all five themes, not the decorative display fonts.
- Cinzel, Rye, IM Fell, Orbitron, Exo now apply to headings and large numbers only.
- Bumped all body text sizes: 9px→11px, 10px→12px, 11px→13px, 12px→13px.
- Increased font weight from 500 to 600 for body text, and to 700 for small labels.
- Raised muted text contrast by roughly 30% across all themes so it's readable on dark backgrounds.
- Increased heading text brightness.
